开源扫雷网绑定用户录像查询 API 约定（草案）

1. 接口定义

GET /api/accountlink/saolei/videos/

用途：扫雷网同步指定绑定账户在开源扫雷网的历史及新增录像。

  • 无需用户密码或登录 token，暂不新增 API Key。
  • 开源扫雷网必须校验 profile 与 saolei_uid 当前存在有效绑定：存在对应 AccountSaolei，且存在对应 AccountLinkQueue(verified=True)。
  • 本接口用于「开源扫雷网 → 扫雷网」方向，不检查 AccountSaolei.auto_sync；该开关控制反方向。
  • 扫雷网是否实际拉取，由扫雷网侧的 openms_link.consent 决定。

2. 请求参数

字段类型必填默认值说明
profileinteger是—开源扫雷网用户 ID
saolei_uidinteger是—绑定的扫雷网用户 ID，用于核验绑定归属
cursorinteger否0上次响应的 next_cursor；返回 id > cursor 的录像
sizeinteger否200本页条数，范围 1–1000

结果按录像 id 升序返回。首次全量同步不传 cursor，之后保存 next_cursor 续拉。

3. 响应外层字段

字段类型必填说明
profileinteger是回显开源扫雷网用户 ID
saolei_uidinteger是回显扫雷网用户 ID
next_cursorinteger/null是本页最后一条录像 ID；无下一页时为 null
has_moreboolean是是否还有下一页
countinteger是本页实际返回条数
generated_atstring是响应生成时间，ISO 8601，必须带时区
itemsarray是录像列表，无数据时返回 []

4. items[] 录像字段

字段类型必填来源说明
idinteger是现有开源扫雷网录像 ID；扫雷网以 (from_site, from_id) 作为幂等键
upload_timestring是现有上传时间，ISO 8601，必须带时区
levelstring是现有b=初级、i=中级、e=高级
modestring是现有开源扫雷网原始模式编码，如 "00"、"05"；必须保留前导零
statestring是现有a=待审、b=冻结、c=通过、d=标识不匹配、e=外站导入
softwarestring是现有a=AVF、e=EVF、m=MVF
timemsinteger是现有开源扫雷网记录的完成时间，单位毫秒
bvinteger是现有本局 3BV
file_extstring是新增原始文件后缀，不带点：avf / evf / mvf
file_sizeinteger是新增原始文件字节数，用于下载前排除超限文件
file_md5string是新增原始文件字节的 MD5，32 位小写 hex，用于下载前查重
download_urlstring是新增原文件完整下载 URL，例如 https://openms.top/api/video/download/12345

其中 timems、bv、level、mode 用于列表展示和预筛选；扫雷网最终落库仍以原始录像文件的解析结果为准。

6. 错误约定

HTTP 状态场景
400参数缺失或格式错误
403profile 与 saolei_uid 不存在有效绑定
429请求超过限速，响应携带 Retry-After
500/502/503临时服务异常，调用方稍后重试

7. 同步口径

  • 列表返回全部 state；扫雷网只导入 a/c/d，排除 b/e，其中 e 用于防止外站录像递归同步。
  • 下载前先用 file_md5 查重，再按 file_size 和 file_ext 预筛选，避免无效下载。
  • download_url 必须返回未经转码的原始文件，并支持直接 GET。
  • ID 游标负责新增录像；建议每天进行一次 cursor=0 全量对账，覆盖审核状态后改等情况。
  • 不提供联系方式、IP 等隐私字段。
