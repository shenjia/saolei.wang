# 3BV 口径不一致扫描结果（2026-10-23）

背景：https://saolei.wang/video/85419（中级，Arbiter 0.52，2014-03-30，wuqifeng(zhejiang)）
页面 3BV 显示 90，但录像播放统计面板显示的分母只有 60。

## 根因（85419）

同一盘面，三种口径三个值：

| 口径 | 值 | 来源 |
|---|---|---|
| 库 board_3bv | **90** | MSSQL 时代旧值（2008 ASP 站写入，同步管线原样沿用；4 连通复算=89，也不等于 90） |
| AVF 文件头自报 | **60** | Arbiter 录制时写入 `B60T...`（八连通口径：7 空区 + 53 独立数字格 = 60 ✓） |
| 播放统计面板 | **60** | 站内回放引擎按文件雷位八连通现算（buildBvStructures），与文件头一致 |

播放器的 60 是对的（真·3BV）；库里 90 是 2008 旧站遗留的错误/异口径数据。
当年入榜 3bvs=2371 = 90×1e6/37960 —— 即榜单十几年来一直按 90 算的。

「播放统计 80」未能在当前生产复现：原地回放 / 全屏回放 / flop 旧版播放器三种形态
播完都是 60/60。若张老师看到的是 80，请告知具体入口（截图更好），怀疑是移动端
或某个旧缓存页面。

## 全库扫描

308,778 条 video_info 全量对本地 avf/mvf 文件核对（308,512 有文件，5 缺失，0 解析失败）：
**库值 ≠ 文件头自报 3BV 的共 71 条**（Clone 50 条 + Arbiter 21 条）。

特征：
- 集中在 2007–2019 老数据（2020 后仅 327251 一条）
- 偏差无规律（±1 到 ±90），非单一算法差异；含 2 条同文件双记录（152656/152657）
- 大偏差样本（85419 差 30、106039 差 90、110987 差 56、28637 差 63、6677 差 109、
  125552 差 30、9025 差 30）当年均按库值入榜
