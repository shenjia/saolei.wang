埋点范围说明：
· 计入：所有前台页面 RSC 导航请求（首页/排行/录像/录像详情/论坛/用户主页/练习等）
· 不计：/api/*、/_next/*、public 静态资源、视频文件、/admin/*（后台自身访问）、favicon、明显 bot UA（含 bot/spider/crawler/curl）

表结构 pageview_log：id / ts（Unix 秒）/ path（255）/ ip_hash（sha256(ip+盐) 截 16 位，不存明文 IP，无个人信息）。索引 (ts, ip_hash) 覆盖 UV 去重。

性能：proxy 内 waitUntil 异步打点不阻塞页面响应；写库走 /api/track（Node runtime + Prisma 单条 INSERT，日 PV 万级无压力）；查询全部挂 unstable_cache（今日 60s、30 天序列 300s）。

上线：本地先 db push 建表验证，生产蓝绿部署时同步 push（当前无 schema 外表阻塞）；上线首日起数据从零累积，历史无法回溯。
