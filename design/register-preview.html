注册页 · 设计方案 /account/register

流程骨架取 2008 ASP 版（注册必读 → 填写信息 → 注册成功），字段与校验取 2013 PHP 版（RegisterForm）， 视觉沿用 legacy-2013.css 的 .box / table.form / .hintMessage / .errorMessage / .button，零新色。
落库沿用新站既有约定：username=邮箱、md5(密码+salt)、事务内 user / user_auth / user_stat 同 id 创建（同扫码注册），注册成功即自动登录。

字段取舍说明（来源 / 校验）
电子邮箱保留2013 版即登录名（username=email，新站登录/找回密码同口径）；格式校验，全站唯一 (注册后不可更改)
登录密码保留2013 规则：6~20 位；落库 md5(密码+salt)，兼容全部老账号
重复密码保留2008 版有、2013 版砍了——建议保留，防手误（两次不一致即报错）
中文姓名保留实名制核心：2~6 个汉字（2013 校验），注册后不可更改
姓名拼音保留每字首字母大写空格分隔（如 Zhang Shen Jia），且字数须与中文姓名一致（2013 校验）
性别保留男/女单选，默认男（两版一致，注册后不可更改）
所在地区保留34 个省级下拉（2008 列表，含 香港/澳门/台湾），地区榜 /area 依赖此字段
登录名称（英文ID）砍掉2008 的 3~12 位英文数字 ID；2013 起已改为「邮箱即登录名」，新站 user_auth.username 存邮箱
网名砍掉2008 可选项；新站对应 user_info.nickname，注册后可在账号中心补填，不挡注册流程
密码提示问题/答案砍掉2008 密保问答已被「邮箱找回密码」替代（password-reset.ts 既定方针）
录像标识文字砍掉2008 三步流程的第二步；新站改为上传录像时按 user_sig 绑定校验，注册环节不强制（降低注册门槛）
